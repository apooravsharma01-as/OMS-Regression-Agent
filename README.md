# Uniware Regression Agent

Centralized API automation and regression testing framework for Uniware.

## Project Structure

- `src/config` - Configuration
- `src/clients` - Common API clients
- `src/modules` - API modules
- `src/utils` - Reusable utilities
- `tests/order` - Order API tests
- `tests/inventory` - Inventory API tests
- `tests/shipping` - Shipping API tests
- `tests/invoice` - Invoice API tests
- `test-data` - Test data
- `reports` - Test reports
- `docs` - Documentation

## Getting Started

Clone this repository and follow the project setup instructions as they are introduced.

## Contribution

All QA team members can contribute through feature branches and Pull Requests.
